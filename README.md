# Zomato Restaurant Data Analysis
Project Overview
This project analyzes Zomato’s restaurant dataset using Power BI to uncover key trends in restaurant ratings, cuisine preferences, pricing, and more. The goal is to deliver actionable business insights for stakeholders in the food delivery ecosystem.

Objectives
Examine the distribution of restaurants by cuisine, location, and cost.

Explore relationships between ratings, average cost for two, and restaurant features.

Provide visual dashboards to aid decision-making for business strategy.
